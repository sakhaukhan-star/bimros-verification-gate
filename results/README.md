# Results and evidence

Everything in this folder was produced by running the scripts in `src/`, `evaluation/` and `tools/` on
`data/BIMROS.ifc`. Gate outputs were produced in offline mode (symbolic layer only); the live LLM runs used the
Claude chat interface because API credentials were not available. Re-running the scripts regenerates these files
in `../output/`.
